# 🍎 Fruit Quality Detection Using Image Processing

## 📌 About the Project

Fruit Quality Detection is a Python-based image processing project that analyzes apple images and identifies their quality condition.

The system detects visible dark or brown spots on an apple, calculates the affected area, and classifies the apple as Fresh, Slightly Spoiled, or Rotten.

## 🎯 Objective

The main objective of this project is to develop a simple system that can analyze an apple image and identify its visible quality condition.

## 🛠️ Technologies Used

- Python
- OpenCV
- NumPy

## ⚙️ Project Working

1. The user provides an apple image as input.
2. The image is processed using OpenCV.
3. The program detects dark or brown spots on the apple.
4. The affected area is calculated.
5. Based on the affected area, the apple is classified as Fresh, Slightly Spoiled, or Rotten.
6. The result is displayed along with the detected spots.

## 📊 Output

The program displays the detected spots on the apple image, affected area percentage, and the final fruit quality classification.

Example results:

- Fresh Apple
- Slightly Spoiled
- Rotten Apple

## ▶️ How to Run

1. Install Python on your computer.

2. Install the required libraries:
   `pip install opencv-python numpy`

3. Keep `fruit_quality.py` and the apple image in the same folder.

4. Open `fruit_quality.py` in Python IDLE.

5. Press **F5** or select **Run → Run Module**.

6. The result will be displayed with the fruit quality classification.
